For your exact setup (browser | terminal | vscode → browser | [terminal/vscode accordion]):

1. Focus the terminal (middle window).
2. alt-shift-; → service mode.
3. alt-shift-l → join-with right. This wraps terminal + vscode into a nested container and drops you back to main mode.
4. alt-comma → switches that nested container to accordion.

If you ever want to break it back apart: focus into the accordion, service mode → r (flatten-workspace-tree) resets the whole workspace.
